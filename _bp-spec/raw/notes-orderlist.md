## ✅ 해소된 의문 (1차 측정 시 미해결이던 129px)
`div.css-1lnshqo.e124gd602` 에 **`max-width: 847px`** 가 걸려 있다.
- 768: 127 + 16 + 545 = 688 ✓ (콘텐츠 미포화)
- 1024: 134 + 16 + 754 = 904 ✓ (미포화)
- 1256+: 160 + **129** + 847 = 1136 → 콘텐츠가 847 에서 포화되어 **잔여 공간이 nav 와 콘텐츠 사이로 분배**된다 (space-between 동작)
→ 즉 미스터리가 아니라 **콘텐츠 컬럼 상한 847** 의 결과.

## 결론
- **리스트 카드는 전 breakpoint 1열.** 카드가 2열로 늘어나지 않는다 (R13 추가 사례).
- 좌측 nav 는 XS 에서 상단 가로 탭바로 전환 (R7 확인).
- nav 폭은 127 → 134 → 160 으로 증가하나 고정 토큰이 아님.
