# PRD — 이사홈 (movingHome)

> **프로젝트**: 오늘의집 이사홈
> **메뉴 트리 루트**: `movingHome`
> **프레임**: 375×812 기준 (Mobile) / Tablet 768 · Desktop 1024 프리뷰
> **관련 문서**: [`../FLOW.md`](../FLOW.md) · [`../LAYOUT_GUIDE.md`](../LAYOUT_GUIDE.md)

## 1. 목적

검증된 이사 파트너에게 **비교견적**을 받도록 유도하는 이사 서비스 진입 홈.
단일 스크롤 페이지에서 (1) 견적 진입, (2) 이사 꿀팁 콘텐츠 소비, (3) 지역 기반 파트너 탐색을 한 화면에 통합한다.

## 2. 핵심 화면 & 기능

| 화면 | 기능 |
|---|---|
| 이사홈 (메인) | ATF 비교견적 유도 · 바로가기 카드(소형/원룸·가정이사) · 꿀팁 캐러셀 · 지역 필터 PLP(무한 스크롤) |
| 콘텐츠 상세 | 이사 꿀팁 아티클(작성자·본문 블록·인게이지먼트·댓글) |
| 견적 신청 | 견적 신청 진입 (현재 준비중 empty state) |

## 3. 사용자 플로우

홈 → (꿀팁 탭) 콘텐츠 상세 / (견적받기) 견적 신청. 상세 위치는 [`../FLOW.md`](../FLOW.md) 참조.

## 4. 주요 인터랙션 스펙

- **지역 필터**: `RegionFilterSheet` 바텀시트에서 시/도 + 구 선택 → PLP 헤딩·목록 갱신
- **이사타입 필터**: 소형/원룸 · 가정이사 칩 (다중 아님, 단일 선택)
- **파트너 목록**: `IntersectionObserver` 무한 스크롤, `motion` 페이드 인, 카드에 평점·리뷰수·포트폴리오 이미지
- **콘텐츠**: `CONTENT_ITEMS` 카탈로그 기반, 카드 탭 시 상세 진입

## 5. 데이터 & 목 생성

- 콘텐츠/파트너 목 데이터는 `scripts/*.mjs` 로 생성 (`generate-content-data`, `generate-partner-mock`, `generate-partner-portfolio`)
- 실 데이터 연동 전까지 목 데이터로 프로토타이핑

## 6. 범위 제외 (CLAUDE 공통 지침)

- 웹 GNB · OS statusbar · 프리뷰 스튜디오/컨트롤 패널은 feature 가 아니므로 구현·QA 대상에서 제외
- 색·타이포·아이콘·컴포넌트는 ODS 토큰/컴포넌트 기준 (이사홈은 `@bucketplace/icons` ODS 아이콘 사용)

## 7. 향후 확장

- ③ 견적 신청: empty state → 실제 견적 입력 플로우(form 프로젝트의 입력폼 플로우) 연결
- 파트너 상세 / 채팅 / 계약(movingpartner 고객단 플로우)과의 연계
